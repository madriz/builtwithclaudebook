About the Book

Twenty-eight days. Five projects in production. Seventy dollars a month to run them all. This is the account of what one person built using Claude as a development partner — and the playbook for doing it yourself.

Who is this book for?

Built with Claude in 28 Days is written for the non-technical founder who wants to build with AI, not just talk about it. If you have ever wanted to ship products with AI but felt locked out because you do not write code for a living, this is a Claude AI tutorial that meets you where you are. It is for the solo founder using AI tools to compete with bigger teams, the product manager who wants to prototype without waiting on a sprint, the operator who has spent years watching engineering ship things you could now build yourself in an afternoon.

The book treats vibe coding as a real skill: how to brief Claude well, how to read what it produces, how to verify the work, and how to stay in control when AI-assisted development hits a wall. By the end you will know how to use Claude as a thinking partner, how to use Claude Code in your terminal on a real codebase, and how to call the Anthropic API directly when you want to build Claude into your own product. It is the same path the author walked to ship five live businesses in 28 days.

Frequently Asked Questions

Can I build software products without knowing how to code?

Yes. The book documents how a non-technical founder shipped five live products in 28 days using Claude as a development partner. The work is not no-code in the template sense. It is AI-assisted development: you describe what you want in plain language, review what Claude produces, and learn enough to verify and direct the work. The book walks through every step, from the first conversation to production hosting.

What is Claude and how does it help non-technical founders?

Claude is an AI assistant made by Anthropic. For solo founders and non-technical builders, Claude functions as a development partner that can read your code, write new features, debug problems, and explain its reasoning. You can use it in three ways: a chat interface for research and writing, Claude Code in your terminal to work directly on a real codebase, and the Anthropic API to embed Claude into your own products.

What is vibe coding?

Vibe coding is a way of building software in conversation with AI rather than by typing every line yourself. You describe what you want, the AI proposes an implementation, you read what it produced, and you push back when it is wrong. It works well when you bring product judgment, taste, and a willingness to test in production. It fails when you stop reading the output. The book treats it as a skill, not a trick.

How much does it cost to run AI-built products?

The five projects in the book run on roughly $70 a month in total infrastructure. Claude itself is a separate subscription that pays back its cost on the first feature it helps you ship. The book covers the full stack: hosting, databases, scrapers, monitoring, and the trade-offs that keep ongoing costs low for a solo founder.

Non-technical founders, solo entrepreneurs, product managers, and operators who want to ship real software with AI rather than read about it in the abstract. What happened to the projects after the book was published?

They kept going, and two new ventures came out of them. HomeGadgets.ca grew from 11,000 products to more than 20,000 unique SKUs across 125+ Canadian retailers, and now runs an MCP server for AI agents, an AI-powered search tool, and an enterprise price comparison API. ShopButler.ai spun out of that infrastructure as a framework for agentic shopping. Credentia.one is an open document standard for job applications. ContextQuant expanded into sector-specific research, Neural Strip still publishes daily, MerchantLink is pre-pilot, and BasketBrain was parked on purpose because the economics of grocery price data did not justify the infrastructure cost. The full progress report is on the project updates page.

What is agentic commerce?

Agentic commerce is online buying where an AI agent does the work on the shopper's behalf: researching options, comparing prices across retailers, checking availability, and in some cases completing the purchase. It depends on machine-readable product and price data rather than pages designed only for human eyes, which is why the author's Canadian price comparison infrastructure became the foundation for ShopButler.ai. The book's Platform Layer chapters cover the underlying pieces: the Anthropic API, MCP servers, and agentic workflows.
