Sobre el libro

Veintiocho días. Cinco proyectos en producción. Setenta dólares al mes para operarlos todos. Este es el relato de lo que una sola persona construyó usando Claude como socio de desarrollo, y la guía práctica para que tú lo hagas también.

¿Para quién es este libro?

28 Días con Claude está escrito para el fundador no técnico que quiere construir con IA, no solo hablar de ella. Si alguna vez quisiste crear productos con IA pero sentiste que estabas fuera porque no escribes código a diario, este es un tutorial de Claude AI que te encuentra donde estás. Es para el emprendedor solo que usa herramientas de IA para competir con equipos más grandes, el product manager que quiere prototipar sin esperar al próximo sprint, el operador que ha pasado años viendo a ingeniería enviar cosas que hoy podría construir él mismo en una tarde.

El libro trata el desarrollo asistido por IA como una habilidad real: cómo briefar bien a Claude, cómo leer lo que produce, cómo verificar el trabajo y cómo mantener el control cuando el desarrollo con IA choca contra un muro. Al final sabrás usar Claude como socio de pensamiento, usar Claude Code en tu terminal sobre un repositorio real y llamar la API de Anthropic directamente cuando quieras integrar Claude dentro de tu propio producto. Es el mismo camino que recorrió el autor para enviar cinco negocios reales en 28 días.

Preguntas frecuentes

¿Puedo construir productos de software sin saber programar?

Sí. El libro documenta cómo un fundador no técnico envió cinco productos en producción en 28 días usando Claude como socio de desarrollo. No es no-code en el sentido de plantillas. Es desarrollo asistido por IA: describes lo que quieres en lenguaje natural, revisas lo que Claude produce y aprendes lo necesario para verificar y dirigir el trabajo. El libro recorre cada paso, desde la primera conversación hasta el hosting en producción.

¿Qué es Claude y cómo ayuda a fundadores no técnicos?

Claude es un asistente de IA creado por Anthropic. Para fundadores solos y personas no técnicas, Claude funciona como un socio de desarrollo que puede leer tu código, escribir nuevas funcionalidades, depurar problemas y explicar su razonamiento. Puedes usarlo de tres maneras: una interfaz de chat para investigar y escribir, Claude Code en tu terminal para trabajar sobre un repositorio real, y la API de Anthropic para integrar Claude dentro de tus propios productos.

¿Qué es vibe coding?

Vibe coding es una forma de construir software conversando con una IA en vez de escribir cada línea tú mismo. Describes lo que quieres, la IA propone una implementación, lees lo que produjo y la corriges cuando se equivoca. Funciona bien cuando aportas criterio de producto, gusto y disposición para probar en producción. Falla cuando dejas de leer la salida. El libro lo trata como una habilidad real, no como un truco.

¿Cuánto cuesta operar productos construidos con IA?

Los cinco proyectos del libro corren con aproximadamente $70 al mes en infraestructura total. Claude mismo es una suscripción aparte que se paga sola con la primera funcionalidad que te ayuda a enviar. El libro cubre el stack completo: hosting, bases de datos, scrapers, monitoreo y las decisiones que mantienen bajos los costos recurrentes para un fundador solo.

¿Qué construyó el autor en 28 días?

Cuatro proyectos y una tira cómica diaria generada con IA. HomeGadgets.ca compara precios de electrónica en 25 retailers canadienses. BasketBrain.ca hace lo mismo para supermercados. ContextQuant extrae señales de sentimiento de reportes de la SEC. MerchantLink es infraestructura B2B de fidelización para bancos canadienses. Neural Strip es un pipeline totalmente automatizado de tiras cómicas con IA. 570 commits, alrededor de 80,000 líneas de código, todo en producción.

¿Es esto un tutorial de Claude Code o un libro general de desarrollo con IA?

Ambos. El libro empieza con la interfaz de chat de Claude.ai y avanza por Claude Code, la API de Anthropic, integraciones MCP y flujos agénticos. Al terminar habrás trabajado cada capa de construir con Claude, con ejemplos tomados de los cinco productos en vivo que el autor envió durante los 28 días.
